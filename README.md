# Individual Addendum — QM 2023 Capstone Project

This repository contains the **Individual Addendum Template** for the QM 2023 Capstone Project, Milestone 4.

## Contents

- [`Individual_Addendum_Template.md`](Individual_Addendum_Template.md) — Fillable Markdown template covering all required sections.

## How to Use

1. Open `Individual_Addendum_Template.md` and fill in every bracketed placeholder with your own content.
2. Export / save the completed document as a PDF named `Individual_Addendum_[YourLastName].pdf`.
3. Add, commit, and push your PDF to the team repository:
   ```bash
   git add Individual_Addendum_[YourLastName].pdf
   git commit -m "Add individual addendum - [Your Name]"
   git push origin main
   ```
